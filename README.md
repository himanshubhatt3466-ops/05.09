# Manas College – Gemini AI Review App

This version removes the old JavaScript template-based review generator. Review drafts are generated by Gemini through a **Cloudflare Worker backend**.

## Important security note
- Do NOT paste your Gemini API key into `index.html`, `worker.js`, or any public GitHub file.
- The API key shared in chat should be revoked/rotated in Google AI Studio before use.
- The key string shared in chat does not look like the usual Google AI Studio key format (`AIza...`). Create/copy the key from Google AI Studio and keep it private.
- Add the replacement key to Cloudflare as a Worker Secret named `GEMINI_API_KEY`.

## 1. Create the Gemini API key
1. Open https://aistudio.google.com/apikey
2. Create a new API key for Gemini.
3. Do not share it or commit it to GitHub.

## 2. Deploy the secure backend (Cloudflare Worker)
1. Open https://dash.cloudflare.com/ and sign in.
2. Go to **Workers & Pages** → **Create** → **Create Worker**.
3. Name it, for example `manas-review-ai`, and deploy the starter Worker.
4. Open the Worker → **Edit code**. Replace its code with the contents of `worker.js`, then Save and Deploy.
5. Open **Settings** → **Variables and Secrets** → **Add** → **Secret**.
6. Name: `GEMINI_API_KEY`; Value: paste your newly created Gemini key. Save.
7. Copy the Worker URL, for example `https://manas-review-ai.<your-subdomain>.workers.dev`.

## 3. Connect the website to the Worker
1. Open `index.html` in a text editor.
2. Find this line near the start of the script:
   `const AI_ENDPOINT='PASTE_YOUR_CLOUDFLARE_WORKER_URL_HERE';`
3. Replace the placeholder with your Worker URL, keeping the quotes, for example:
   `const AI_ENDPOINT='https://manas-review-ai.<your-subdomain>.workers.dev';`
4. Save `index.html` and upload the app folder to GitHub Pages or your hosting.

## 4. Test
- Open the deployed website.
- Select a rating, enter keywords and optional genuine details.
- Click **Generate with Gemini AI**.
- The AI-generated draft appears in the editable preview.
- Click **Continue to Google Reviews**. The Google review page opens and the draft is copied when browser permissions allow. Paste it into Google and submit manually.

## Notes
- Google does not provide a supported way for this website to auto-fill and submit a review in Google's interface. The user must review, paste, and submit it.
- The Worker uses the Gemini `generateContent` REST API with the `gemini-3.8-flash` model.
- Keep the Worker URL public if the website is public, but keep the API key only in the Worker Secret.
- Add Cloudflare rate limiting before public launch to reduce abuse and quota exhaustion.
- Only publish reviews that reflect the reviewer's real experience.
